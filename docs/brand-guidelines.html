04 / Usage 使用规范留白、最小尺寸与安全区

Clear Space 安全留白

≥ 图标半径

标志四周保留不小于「图标圆角半径」的空白；图文组合标以字母高度为间距基准，禁止其他元素侵入。

Minimum Size 最小尺寸

图标 32px

数字界面中图标边长不小于 32px；组合标宽度不小于 160px，确保「Ai」笔画与字标清晰可辨。

On Color 底色适配

深蓝 / 浅色

深色底用反白标；浅色底用深蓝或亮蓝标。避免将深蓝标放在低对比灰底上。

Alignment 对齐

左 / 居中

组合标默认左对齐或水平居中，图标与字标基线对齐，禁止拉伸、倾斜或旋转。

05 / Rules 禁忌正确与错误用法

✓ 推荐做法

  • 使用提供的标准渐变或单色深蓝版本
  • 保持足够留白，让标志成为视觉焦点
  • 深色背景使用反白标志
  • 缩放时整体等比例，保持笔画粗细一致

✕ 禁止做法

  • 不要更改标志主色或渐变角度
  • 不要给标志添加投影、描边或特效
  • 不要拉伸、压扁、旋转或倾斜标志
  • 不要将标志与过多装饰元素混排
