## 三、各角色职责详述

### 1. 产品经理 —— 赵国旭（1）

- 搭建 Spark 集群与 ETL 流水线，部署 PMML 模型推理服务，设计分布式集群方案。
- 主笔《需求分析报告》《详细设计报告》。

### 2. 测试工程师 —— 李定晨（2，大哥）
- 编写测试用例，执行功能测试、性能测试与安全性测试，记录缺陷与回归结果，输出《系统测试报告》。

- **李定晨（大哥）额外职责**：独立负责第二部分"Spark 数据处理与数仓 ETL"，详见第四节。

### 3. 后端开发工程师 —— 杜心浩（3）、白天航（4）
- 杜心浩：Spark 性能调优、模型评估指标、随机森林模型训练、KMeans+PCA 聚类、ES 索引设计与同步；主笔模型相关文档。

### 4. 前端开发工程师 —— 王宛强（5）
- 基于 Vue3 + ECharts 实现 5 块数据大屏（总览 / 画像 / 关联 / 预测 / 检索）。
- 对接后端 REST 接口，仅做数据渲染，不做复杂计算（计算已由数据处理层预完成）。

## 四、第二部分（数据处理层）—— 李定晨（2号，大哥本人）

> 这一层是整个系统的"中央厨房"，由李定晨（大哥）独立承担。
> 说明：李定晨的团队角色归类为**测试工程师**，但本项目里独立完成了通常归后端 / 数据工程师的**数据处理层**核心工作，属于"测试 + 数据处理"双职责。

**技术栈**：Spark 3.5 + Hive Metastore + HDFS

**核心工作（对应 `run_pipeline.py` 流水线）**：

| 步骤 | 函数 | 做的事 | 产物 |
|---|---|---|---|
| 1 上传 | `step1_upload_to_hdfs` | 原始 CSV 上传到 HDFS `/tmp` | 贴源数据 |
| 2 建表 | `step2_create_hive_tables` | 建 ODS/DWD/DWS/ADS 四层 Hive 表 | 数仓骨架 |
| 3 清洗+特征 | `step3_ods_to_dwd` | 去重、空值/异常过滤、年龄分桶、BMI、地区解析、阶段占比归一化 | `dwd_sleep_detail`（约 5.8 万条） |
| 4 聚合 | `step4_dw_aggregation` | 年/月趋势、地域、设备、年龄段汇总、皮尔逊相关性矩阵 | DWS / ADS 聚合表 |
| 5-6 模型 | `step5/step6` | 随机森林回归 + KMeans 聚类（**归第三部分 ML 同学杜心浩**，训练数据来自本层 DWD） | 模型结果 |
| 7 同步 ES | `step7_sync_to_es` | 明细写入 `sleep_records` 索引 | 屏5 检索 / 屏3 气泡图 |
| 8 同步 MySQL | `step8_sync_to_mysql` | 13 张聚合结果表 JDBC 双写 | 屏1/2/3/4 接口数据源 |

**一句话定位**：
> "我是数据处理层，整个系统的'中央厨房'。上游 CSV 进来，下游大屏要的每张图、每个数，都是我这层 Spark 离线算好、分层存好，再分发给 MySQL 和 ES 的。前端只管画，数据是我备的。"

## 五、关于"角色标签"与"实际职责"的说明（答辩防追问）

- 团队按 4 类角色划分时，**李定晨（大哥）归类为测试工程师**；但在实际研发中，他独立扛下了**第二部分数据处理层（Spark ETL / 数仓 / 双写）**这一最重的核心模块。
- 答辩建议说法：
  > "我们组按产品经理 / 测试 / 后端 / 前端四个角色划分。我是测试工程师李定晨，但项目中我额外重点负责了**数据处理层**的设计与实现——也就是用 Spark 把原始数据清洗、建数仓、算指标、再同步给 MySQL 和 ES，这部分是大屏数据的基础；同时我也承担了功能、性能、安全的测试工作并输出了测试报告。"
- 这样讲既诚实（承认自己挂测试名），又突出了你**第二部分的核心贡献**，老师反而会觉得你能跨栈、扛得住重活。

## 六、模块划分与角色边界（答辩防追问用）

- **前端 ≠ 计算**：所有统计、聚合、特征工程都在数据处理层完成，前端只渲染。
- **产品经理 ≠ 编码**：负责架构选型与需求设计，不直接写业务代码。
- **测试 ≠ 只测**：李定晨挂测试名，但实际额外承担数据处理层核心编码。
- **第二部分（ETL）归属李定晨（大哥）**：屏3 的"相关性矩阵"是第二部分用 Pearson 相关算出来的，**属于第二部分**，不是 ML 部分。
- **机器学习（随机森林/KMeans）归属杜心浩（后端）**：训练数据来自李定晨清洗好的 DWD 表——被问到就说"模型是杜心浩训的，特征数据是我这层供的"。
