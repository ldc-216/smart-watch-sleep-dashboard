# 信阳师范大学本科毕业论文（设计）标准格式规范与模板参考

> 说明：以下规范整理自信阳师范大学（原信阳师范学院）教务处及院系官方文件。
> 你当前是「数据科学与大数据技术」专业，属于**理工类**，下面以理工类格式为主、文史类为辅。
> 校名注意：学校已更名为「信阳师范大学」，老文件里写的「信阳师范学院」是同一所学校。

---

## 一、标准装订顺序（整套材料）

按以下顺序装订成册，**一式二份**（一份入学生档案，一份学院留存）：

1. 封面（学校统一模板）
2. 目录
3. 正文（含中英文摘要、关键词、前言、各章节、参考文献、附录）
4. 附录（按需，可有可无）
5. 开题报告
6. 指导教师评语表
7. 评阅人评议表
8. 答辩记录表
9. 成绩评审表

> 另：中期检查表、指导日志、检测报告等过程性材料单独装袋，由学院留存。

## 二、理工类正文排版格式（重点，你的专业适用）

| 内容 | 字体字号要求 |
|---|---|
| 论文大标题 | 宋体三号，**加黑**，居中 |
| 学生姓名 / 学号 / 专业 / 指导教师 / 职称 | 五号宋体，不加黑，居中 |
| 一级标题（如 `1 XXXX`） | 宋体四号，**加黑** |
| 二级标题（如 `1.1 XXXX`） | 宋体小四号，**加黑** |
| 三级标题（如 `1.1.1 XXXXX`） | 仿宋体小四号 |
| 正文内容 | 宋体小四号，不加黑 |
| 图表说明 | 宋体小五号，不加黑（表说明在表**上端**，图说明在图**下端**） |
| 「摘要」二字 | 黑体小四 |
| 摘要内容 | 楷体小四号，不加黑 |
| 「关键词」三字 | 黑体小四 |
| 关键词内容 | 楷体小四号，不加黑 |
| 「Abstract」 | Times New Roman 小四，加黑 |
| 英文摘要内容 | Times New Roman 小四，不加黑 |
| 「Keywords」 | Times New Roman 小四，加黑 |
| 英文关键词内容 | Times New Roman 小四，不加黑 |
| 目录标题「目录」 | 黑体三号，**加黑**，居中（目录与列表间空 2 行） |
| 目录各条目 | 宋体小四号，1.5 倍行距 |

**目录结构示例（理工类）**
```
目         录
摘要 ........................................ x
Abstract .................................... x
1 绪论 ...................................... x
  1.1 研究背景 .............................. x
    1.1.1 嵌入式系统的应用 ................ x
  1.2 研究意义 .............................. x
2 硬件/系统设计 ............................ x
参考文献 .................................... x
```

**其他通用要求**
- 正文从第 1 页开始编页码（即「摘要」那页为第 1 页），页码位于页面底端居中，半角数字 1、2、3。
- A4 纸**单面**打印，Word 编辑排版。
- 论文字数 **4000 字以上**。
- 参考文献一般 **12–18 篇**，半数以上应为最新研究成果文献；引用序号标在正文引用处文字末、句号前，加 `[ ]` 标于右上角。
- 图表及其说明要排在同一页内，不允许跨两页。

**参考文献著录格式（理工类，参照《信阳师范学院学报》自然科学版）**
- 期刊：`作者. 文题[J]. 刊名, 年, 卷(期): 起页-止页.`
- 专著：`作(编)者. 书名[M]. 版次. 出版地: 出版者, 年份: 起页-止页.`
- 学位论文：`作者. 论文题名[D]. 保存地: 保存者, 答辩年.`
- 析出文献：`主要责任者. 析出文献题名[C]//原文献主要责任者. 原文献题名. 出版地: 出版者, 出版年: 起止页码.`
- 电子文献：`主要责任者. 电子文献题名[EB/OL]. (发表日期)[引用日期]. 出处或地址.`
- 内部资料、个人通讯、报纸及未公开发表的文章不得作为参考引文。

## 三、文史类正文排版格式（备查）

| 内容 | 字体字号要求 |
|---|---|
| 论文大标题 | 宋体三号，**加黑**，居中 |
| 一级标题（如 `一、XXX`） | 宋体四号，**加黑** |
| 二级标题（如 `（一）XXX`） | 仿宋体小四号，**加黑** |
| 三级标题（如 `1. XXX`） | 宋体小四号 |
| 前言 | 宋体小三号，**加黑**，首行缩进两字符 |
| 正文内容 | 宋体小四号，不加黑（正文中的数字也要统一为宋体） |

文史类目录用「一、」「（一）」「1.」层级，其余摘要/关键词/英文部分同理工类。

## 四、开题报告填写要点（院系通用要求）

- 按教务处模板填写，各项数据前后一致。
- **选题意义及内容**：分两小段——先谈选题意义，再谈研究内容。
- **思路及方法**：分两小段——先谈思路，再谈研究方法。
- **进度安排**：至少分三段——查阅文献确定选题；研究过程（重点）；论文写作及修改。
- **指导教师意见**：填 5 行左右。

## 七、一句话总结给答辩/写作用

> 信阳师范本科论文 = **封面 + 目录 + 中英文摘要/关键词 + 前言 + 分级标题正文（理工类用 1 / 1.1 / 1.1.1）+ 参考文献（12–18 篇，右上角 [n] 标注）+ 附录**，A4 单面打印、4000 字起、Word 排版，一级标题宋体四号加黑、正文宋体小四。模板直接去教务处链接下「附件 1–17.zip」最全。
